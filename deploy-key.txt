填写步骤
--------
1. 在 GitHub 新建（或使用已有）空仓库，拿到 SSH 地址，形如：
   git@github.com:<你的账号>/<仓库名>.git
2. 仓库 → Settings → Deploy keys → Add deploy key
   - Title: hghub-ios-deploy
   - Key: 粘贴上面那一整行公钥
   - Allow write access: 勾选（推送代码必须）
3. 把仓库 SSH 地址发给助手，即可推送并在 Actions 里构建 IPA。
